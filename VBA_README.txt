--------------------------------------------------------------------------------
OVERVIEW
--------------------------------------------------------------------------------

The VBA macros add live error checking to the master ringing data workbook
(.xlsm). As you enter data in the field, cells are highlighted red immediately
if a problem is detected — so you can correct errors while the bird is still
in the hand.

Checks performed on every cell change:
  1. Species code not recognised
  2. Wing measurement outside expected range for that species
  3. Weight outside expected range for that species
  4. ringType = N but ring number already exists (prior record found)
  5. ringType = R but ring number not found (no prior record)
  6. Sex conflicts with a previous record of the same bird
  7. Species conflicts with a previous record of the same bird

A red cell also shows a comment (hover over it) explaining the problem.

Additional tools:
  - Ctrl+Shift+R  fills the active cell with the next ring number in series
  - CheckAllRows  macro re-checks every row (run after updating Individuals tab)


--------------------------------------------------------------------------------
SHEETS REQUIRED
--------------------------------------------------------------------------------

The macros look for three sheets in the workbook:

  "Ringing data"   your main data entry sheet (must exist)
  "Individuals"    generated by build_individuals_table.py (must be kept
                   up to date — see fieldemon README.md for workflow)
  "Species list"   manually maintained lookup table (set up once, see below)

If either Individuals or Species list is missing when you open the workbook,
a warning message will appear and the affected checks will be skipped rather
than crashing.


--------------------------------------------------------------------------------
SPECIES LIST SHEET SETUP (one-time)
--------------------------------------------------------------------------------

Create a new sheet in the workbook called exactly:   Species list

Set up the following columns with headers in row 1:

  A: Code        (species code, e.g. BLUTI)
  B: Name        (common name, e.g. blue tit)
  C: Ring size   (e.g. A)
  D: Min wing    (minimum wing length in mm)
  E: Max wing    (maximum wing length in mm)
  F: Min weight  (minimum weight in grams)
  G: Max weight  (maximum weight in grams)

Data starts in row 2. Copy the following starter data into the sheet:

wing and weight checks are silently skipped for that species — no false
positives.


--------------------------------------------------------------------------------
INSTALLATION
--------------------------------------------------------------------------------

Step 1 — Open the VBA editor
  Open your .xlsm workbook in Excel.
  Press Alt+F11 to open the Visual Basic editor.
  In the Project panel on the left you will see your workbook listed.
  Expand it by clicking the arrow next to it.

Step 2 — Install the Workbook_Open and Workbook_BeforeClose code
  In the Project panel, double-click "ThisWorkbook" under your workbook.
  Paste the following code into the editor window that opens:

    Private Sub Workbook_Open()
        SetRingShortcut
        Dim missing As String
        missing = ""
        If Not SheetExists("Individuals") Then
            missing = missing & "  - Individuals" & vbCrLf
        End If
        If Not SheetExists("Species list") Then
            missing = missing & "  - Species list" & vbCrLf
        End If
        If Len(missing) > 0 Then
            MsgBox "Fieldemon: the following sheets are missing and error " & _
                   "checking will not work correctly:" & vbCrLf & vbCrLf & _
                   missing & vbCrLf & _
                   "Run build_individuals_table.py and copy the Individuals " & _
                   "tab into this workbook, and ensure a Species list sheet " & _
                   "exists.", vbExclamation, "Fieldemon"
        End If
    End Sub

    Private Sub Workbook_BeforeClose(Cancel As Boolean)
        ClearRingShortcut
    End Sub

Step 3 — Install the Worksheet_Change code
  In the Project panel, expand "Microsoft Excel Objects" and double-click
  the sheet named "Ringing data".
  Paste the following code into the editor window that opens:

    Private Sub Worksheet_Change(ByVal Target As Range)
        If Target.CountLarge > 1 Then Exit Sub
        If Target.Row < 2 Then Exit Sub
        If Target.Column > 24 Then Exit Sub
        Application.EnableEvents = False
        On Error GoTo Cleanup
        CheckRow Target.Row
    Cleanup:
        Application.EnableEvents = True
    End Sub

Step 4 — Install the main module
  In the Project panel, right-click on "Modules" (or on the workbook name
  if Modules doesn't exist yet), choose Insert > Module.
  A new module window will open.
  Paste the entire contents of fieldemon_macros.bas into it.

Step 5 — Save
  Close the VBA editor.
  Save the workbook (Ctrl+S). Make sure it is saved as .xlsm (macro-enabled
  workbook), not .xlsx.

Step 6 — Test
  Close and reopen the workbook. You should see no warning messages if the
  Individuals and Species list sheets are present.
  In the Ringing data sheet, type an unrecognised species code (e.g. XXXXX)
  in the species column of a new row and press Tab. The cell should turn red.
  Press Ctrl+Shift+R in any cell to test the ring number shortcut.


--------------------------------------------------------------------------------
RING NUMBER SHORTCUT — Ctrl+Shift+R
--------------------------------------------------------------------------------

Press Ctrl+Shift+R with any cell selected to fill that cell with the next
ring number in series.

How it works:
  - Looks up the last non-empty ring number in the ringNo column
  - Splits it into a letter prefix (e.g. ABR) and a numeric suffix (e.g. 6001)
  - Increments the number by 1, preserving leading zeros and total length
  - Writes the result into the active cell

Examples:
  ABR6001  →  ABR6002
  BLK5086  →  BLK5087
  TT05153  →  TT05154

If you have switched ring series mid-session, the shortcut will increment
from whatever the last ring number entered was. You can always type over the
result if it is wrong.


--------------------------------------------------------------------------------
RECHECKING ALL ROWS
--------------------------------------------------------------------------------

After you copy a fresh Individuals tab into the workbook (following a new
run of build_individuals_table.py), you should recheck all rows to catch
any conflicts with the updated data.

To do this:
  Press Alt+F11 to open the VBA editor.
  In the Immediate window (Ctrl+G to show it), type:
    CheckAllRows
  and press Enter.

Alternatively, you can assign CheckAllRows to a button on the sheet.
A message box will confirm how many rows were checked when it finishes.


--------------------------------------------------------------------------------
IF SOMETHING GOES WRONG
--------------------------------------------------------------------------------

Macros stop running / red highlighting stops appearing:
  This usually means an unhandled error caused Application.EnableEvents to
  be set to False. To fix it, open the VBA editor (Alt+F11), open the
  Immediate window (Ctrl+G), type:
    Application.EnableEvents = True
  and press Enter. Then close the editor.

Ctrl+Shift+R does not work:
  The shortcut is registered when the workbook opens. Close and reopen the
  workbook. If it still does not work, open the VBA editor, open the
  Immediate window, type:
    SetRingShortcut
  and press Enter.

Species list changes not picked up:
  The lookup reads the Species list sheet live each time — no restart needed.
  Just add or edit rows in the sheet and the next cell change will use the
  updated data.

Individuals tab is out of date:
  Run build_individuals_table.py, copy the Individuals tab from the output
  workbook into the master .xlsm, then run CheckAllRows.
